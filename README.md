# Wox.Plugin.Mole

> Dig deep like a mole to optimize you Mac.

Wox plugin for https://github.com/tw93/Mole

## Features
- Run `mole clean` directly from Wox and see live progress updates.
- Preview cleanup safely with `mole clean --dry-run`.
- Live preview pane shows streamed Mole output; result tail shows a small progress ring.
- Toggle actions swap between start/stop while a clean is running.
- Shows friendly status messages even when Mole runs in non-interactive mode.

Ensure the `mole` CLI is installed (`brew install mole`) before running the plugin actions.
